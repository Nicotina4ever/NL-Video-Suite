# Runtime opzionale

Questo repository non contiene Python, DLL o pesi. Il Core usa Rust+FFmpeg esterno e puo aprire l'editor senza IA. Per i backend Python riusa un interprete compatibile; il file requirements-installed.txt descrive il runtime locale di riferimento, non e un installer universale CPU/CUDA e non scarica modelli. Vedi ../documentazione/MANUALE.md.
